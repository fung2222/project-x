# Project X 可靠性及網站更新（2026-11-09）

## 今次目標

將全站審核發現轉成可部署修正，而唔係只出報告。金融策略門檻保持不變，冇為改善回測數字調參。

## 已完成

### 1. 回調掃描端到端整合

- 新增 `px/jobs/pullback.py`，將原本獨立 stdout/stderr 工具納入 `run.py`、主 schedule、run ledger 及 watchdog。
- 09:00 ET（NYSE 開市前 30 分鐘）執行，沿用 `px/clock.py` 處理 DST、假期及交易日。
- Universe 同四條門檻移入 `config/settings.json`；仍係 45 隻、8–18% 回調、MA50 1.00–1.05、MA50 十日斜率向上及 63 日回報 > 0。
- 完整零命中 = `ok`、Telegram 靜默；任何股票數據不足、舊 bar 或請求失敗 = `failed`，唔會假裝零命中。
- 命中先發 Telegram，沿用 duplicate guard；通知失敗會進入重試。
- 每次寫 `data/pullback.json`：開始／完成／最近成功時間、bar date、掃描數、命中數、失敗清單及規則。初始 `pending` 只代表未執行。
- 舊外部 cron 應停用；`scripts/pullback_scan.py` 變成主 CLI 相容入口。

### 2. 策略及風控口徑

- 動能／突破掃描改名為研究名單，移除「核心產品」暗示，同回調策略明確分開。
- 「建議注碼」改為「模擬注碼（預算參考）」；「分數」改為「機會評分」。
- VOO 核心長線定投同衛星個股學習倉分層顯示，加入市值佔比及入場至止蝕風險。
- 手續費統一：每張單最低約 US$2，一買一賣約 US$4，另有交收費及賣出 TAF。
- 回測弱點及「唔係買入建議」保留，冇改金融參數。

### 3. 全站 UX／無障礙

- 七個主頁各有一個 H1，加入跳到主要內容連結及一致 `:focus-visible`。
- Logo 可返回首頁；現頁導覽有 `aria-current="page"`，手機會自動將 active tab 捲入可見範圍。
- 寬表格喺 ≤600px 變成有欄位標籤嘅資料卡，唔再依賴約 1,400px 橫向捲動。
- 報告有按鈕式篩選、`aria-pressed`、每頁 20 份、上下頁及即時結果數目。
- SVG 圖表加入 title、desc 及屏幕閱讀器角色。
- 灰字、警告、上升及下跌配色對比提高；支援 reduced-motion。
- 回調頁由過時靜態計劃書改為讀取真實掃描狀態；載入失敗會明示故障。

## 部署步驟

1. 將今次檔案更新到 `main`，確認 GitHub Pages 正常。
2. Hermes 維持每分鐘 `ops/hermes/px_job.sh tick`，唔需要新增獨立回調 cron。
3. **停用舊 `pullback_scan.sh` 外部 cron**，避免重複通知。
4. 先跑 `python run.py status`，再喺窗口內用 `python run.py pullback --dry-run` 驗證數據來源。
5. 下一個 NYSE 交易日 09:00 ET 後，檢查 `data/pullback.json`、run ledger 及回調頁狀態。
6. 若 Yahoo cooldown 生效，tick 會延後而不消耗嘗試次數；失敗重試及告警沿用現有 watchdog。
