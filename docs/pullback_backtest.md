## 回測設定（預先定義、可重複）

- **Universe**：45 隻大型藍籌（科技／消費／醫療／金融／工業）
- **訊號**：3 月回報 > 0 ＋ 離 52 週高位 −8% ~ −18% ＋ MA50 向上 ＋ 收市企穩 MA50（1.0–1.05）
- **買入**：訊號後下一交易日開市價（避免用未公開數據）
- **止損**：−8%（固定）
- **止盈**：+16%（固定 2R）
- **時間止損**：30 交易日未觸發就退出
- **手續費**：每筆 $2 買 ＋ $2 賣（來回 $4）
- **持倉上限**：3 隻；每注 = 本金 25%（初始 US$10,000）
- **時期**：2021-11 → 2026-11（約 5 年，1255 交易日）
- **基準**：SPY 買入持有

## 誠實嘅紅旗（唔可以忽視）

1. **盈利高度集中喺 2024 年**：2024 一項 +$6,166 佔總盈利（$11,142）嘅 55%。冇咗呢年，5 年回報大幅縮水。2024 正正係 AI 股大牛市——即係話呢個策略嘅「超額回報」好可能主要嚟自一段牛市，而唔係穩定嘅 edge。

2. **近年勝率跌到 42–43%**：2025、2026 兩年勝率都低過一半，係靠「賺多蝕少」（PF 1.49）先維持正數。呢個喺「震盪／下行市」會好脆弱。

3. **Sharpe 0.18（近似）極低**：雖然總回報跑贏 SPY，但係風險調整後嘅表現其實差。呢個 Sharpe 係用「每筆交易」粗計，未用時間序列權益，下一步要重計。

4. **倖存者偏差（未修正）**：Universe 係「而家」嘅 45 隻藍籌。5 年前有啲公司可能未上市／未算藍籌／已經被淘汰。真正回測應該用「當時」嘅成分股，呢個係最大嘅潛在偏見。

5. **未做 Walk-forward**：參數（−8% ~ −18%、MA50、1.0–1.05）係人手揀，可能 overfit 咗呢段歷史。要分訓練期／測試期再驗證。

## 精準回測（v2，修正現金限制後）— 2026-11-09 更新

v1 嘅「+111%」有漏洞：佢假設每筆交易獨立用 $2,500，冇計「同時最多 3 隻 + 現金 $10,000」嘅現實限制。v2 用 portfolio simulation（每日 mark-to-market + 現金流）重跑，結果反轉：

| 指標 | v1（簡單，偏樂觀） | v2（精準，portfolio） |
|---|---|---|
| 交易次數 | 276 | 120 |
| 總回報 | +111.4% | **+51%** |
| SPY 同期 | +67.6% | **+67.6%** |
| Sharpe（時間序列） | 0.18（粗計） | 0.91 |
| 最大回撤 | -12.0% | -16.1% |

**結論：精準版策略 +51%，跑輸 SPY +67.6%。之前「跑贏」係計法錯誤造成嘅假象。**

### Walk-forward（訓練 2021-11~2023-10 vs 測試 2023-11~2026-11）

## 最終結論（誠實）

**「回調位策略」計埋現實限制後，長線跑輸買入持有 SPY。唯一作用是熊市跌少啲，代價是牛市大幅跑輸。策略沒有穩定 edge，參數敏感（過度擬合）。**

對 Roy 嘅含義：**VOO 定投先係正確主線。回調掃描只適合作為「熊市跌少啲」嘅輔助，不應視為長期跑贏策略。** 呢個係「用回測發現」嘅免費教訓，好過用真錢發現。
